# GearV — Landing page

Sitio estático de GearV (gearvagency.com), publicado en Vercel desde la rama `main`.

## Estructura
- `index.html` — la página (estilos y scripts incluidos).
- `assets/` — logo, favicons, imagen para redes (`og-image.jpg`), foto de equipo y logos de marcas y partners.
- `vercel.json` — caché de 7 días para las imágenes de `assets/`.

## Publicar
Subir los cambios a `main` en GitHub. Vercel publica solo en uno o dos minutos.

## Medición
- Vercel Web Analytics: el script ya está en `index.html`. Debe estar activado en Vercel → proyecto gearv → Analytics → Enable.
